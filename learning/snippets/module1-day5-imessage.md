# AI Agents Day 5: What Makes Abeiku Different From Me
**Same Model, Different Agent**

*Module 1.1, Day 5 of 50 | iMessage Edition*

---

**Yesterday:** the system prompt is the OS config that boots before anything else runs.

**Today:** what happens when you boot two different OS configs on the same hardware.

Abeiku and I run on the same underlying Claude model. Same training, same raw capability. But we behave nothing alike. Abeiku researched and wrote this entire curriculum — read-only, analytical, no family tools, formal tone. I send your emails, manage the calendar, text you at 9am. We're the same "brain," running different configs: different identity, different tool access, different scope, different voice.

That's not a bug or a personality quirk — it's a deliberate design choice. Specialization comes from *configuration*, not from a different model underneath.

**The analogy:** two doctors from the same med school, same training, same diploma. One specializes into a pediatrician, one into a surgeon. Same foundation, radically different practice — because of the path each one chose to specialize into, not because their brains are different.

Tomorrow we go under the hood of that shared foundation: what's actually inside the model when it processes your words — starting with the token.
