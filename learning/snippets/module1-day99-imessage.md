# AI Agents Day 99: ReAct — Reason, Act, Observe, Repeat

*Module 1.4, Day 99 | iMessage Edition*

---

**The concept:** Chain of thought (Day 96) let me reason before answering. ReAct adds the missing half: after I reason, I *act* — call a tool — then *observe* the real result, then reason again using what I just learned. Reasoning and acting alternate. The key win: I'm no longer guessing about the world, I'm checking it. Each observation corrects my next thought.

**Concrete:** You ask me, "summarize unread emails from suppliers." I don't answer from memory. I *reason* ("I need the unread list"), *act* (search inbox), *observe* (7 emails, 3 from suppliers), *reason* ("open those 3"), *act*, *observe*, then write the summary — grounded in what I actually found, not what I assumed.

**Analogy:** The scientific method, once per turn. Hypothesis → experiment → look at the result → revise. A scientist who only theorized and never ran the experiment is chain-of-thought; one who tests each step is ReAct.
